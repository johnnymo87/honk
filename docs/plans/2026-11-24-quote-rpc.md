## Contract (pigeon's, unchanged)

Request on a viewer connection:
`{sessionId, pick: {kind: since}|{kind: prev}|{kind: last, n}, full?, tag?, quoteId?}`;
`_honk/quote/cancel {quoteId}` cancels, and so does closing the connection.

Reply: `{summary, replies: [{header, passages: [[line…]…], inProgress}], notices, warnings,
empty, model}`. `summary` is honk's first `#` line (null when untrimmed). `header` is exactly the
composer's header line, tag (` · ask`) or ` · untrimmed` included. Lines are unquoted.
`empty`: null | no_replies | never_spoke | nothing_since | one_prompt | nothing_kept, the reason
also in `notices`. Unknown session: JSON-RPC error -32602. Cancelled: -32800.

honk chat's composer text = `summary` (if any), then per reply `header\n` + passages, each
`quote_lines`'d, joined by `\n# …\n`; blocks joined by `\n\n`. Identical to today's output.

## Design

- **honk-wire `quote`**: serde types for request/reply (both sides), `quote_lines`, and
  `composer_text(reply)`.
- **honkd `quote` module** (moved from `crates/honk/src/tui/{quote,trim}.rs`):
  - `turns`: streams `state_dir/sessions/<sid>.jsonl` line by line (BufReader; never loads the
    session into goose, never holds the whole file), keeps only `user_message_chunk` /
    `agent_message_chunk` text, keyed by message id in first-appearance order (as honk's
    transcript does), and rebuilds turns. Runs on a blocking thread. sid validated
    (no path separators).
  - `pick`: today's `quote::build` over turns, plus the fallbacks honk chat did
    (one_prompt → since, never_spoke → last 3, "only N replies").
  - `trim`: today's `trim.rs` (SYSTEM, batches, batch_prompts, parse, merge) unchanged; render
    produces the structured reply instead of text.
  - running = `hub.is_session_running(sid)` (held + active run) marks the last turn in progress.
  - answer cache: small LRU in the hub (16 entries) keyed by hash of the batch prompts; only
    fully good answers cached (as today).
  - model calls: `hub.oneshot` per batch, PARALLEL=4, each with its own cancel; quote cancel
    fires them all.
- **Spend tag**: `tag` param > program of a stall-watch coordinator (cwd
  `…/stall-watch/coord-sessions/<tag>-<ms>`, from honkd state for a held session) > tagFrom
  the quoted session. `_honk/oneshot` also takes `tag` (overrides `tagFrom`).
- **honk chat**: `/quote` parses args as today, sends `_honk/quote` on its own connection
  (as run_trim did), shows a "quoting…" notice for trimmed forms, maps the reply to notices +
  composer text. Ctrl-C / sending a prompt / `/quote full` aborts the task (closing the
  connection cancels in honkd). Old client-side quote.rs/trim.rs deleted.
