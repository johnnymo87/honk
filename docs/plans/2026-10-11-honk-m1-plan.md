# honk M1 (honkd relay) Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (or
> subagent-driven-development) to implement this plan task-by-task.

**Goal:** Build `honkd`, a mostly transparent ACP proxy. It holds goose sessions over
HTTP+SSE with persisted connection ids, fans `session/update`s out to any number of
WebSocket viewers, and keeps turns, pending permissions, prompt queues and
idempotency across viewer detach, honkd restarts and goose restarts. Also build a
~150-line `honk tail` / `honk list`, so that pigeon's turns are visible from a
terminal.

**Architecture:** honkd routes raw `serde_json::Value` JSON-RPC (design §4). It
decodes only `method`, `id`, `sessionId` and the messages it owns. Each held session
is one actor task that owns one `honk_upstream::Upstream` (one logical HTTP+SSE
connection, A4), an append-only `(epoch, seq)` log, pending server→client requests,
and a pure `TurnCore` that handles prompt, queue and steer. A hub owns the control
connection (`session/list`, export), the state file and the session limits.
Downstream is axum WebSocket on `127.0.0.1:4280/acp`. The pure logic (reconcile,
turn core, state file, tail renderer) is unit-tested. The actor behavior is tested
against an in-process fake goose (`honk-fake-goose`) that speaks the measured goose
HTTP+SSE wire. Live `#[ignore]` tests on the sandbox (:4180) prove the M1 exit
criteria.

**Tech Stack:** Rust 1.99.0 (edition 2024), tokio, axum (`ws`), reqwest +
eventsource-stream (via `honk-upstream`), tokio-tungstenite (clients and tests),
serde_json, clap, tracing, tracing-subscriber, tokio-util (`CancellationToken`),
tempfile. Nix dev shell. GitHub Actions CI (unchanged: fmt, clippy `-D warnings`,
test).

**Read first:** `docs/plans/2026-10-10-honk-design.md` §3–§6 and §8, and
`docs/spike/m0-findings.md` (Summary plus amendments A1–A16).

## Ground rules

- **The production goose is off-limits until Task 24, and Task 24 is author-gated.**
  Production listens on 127.0.0.1:4080. `guard_url` refuses that port unless honkd
  gets `--allow-production-upstream`. All M1 tests use the fake goose (in-process,
  ephemeral port) or the sandbox (`honk-goose-sandbox` user unit on :4180). Never
  run `goose` without an absolute `GOOSE_PATH_ROOT`.
- **Never DELETE an upstream connection to fix a stuck subscriber** (A2). DELETE
  cancels the run. DELETE is used only for idle eviction (A14), orphan cleanup
  (A15), and an explicit `_honk/hard_cancel` (A8). Never send `session/close`
  upstream, because it cancels any connection's run (§3). Never send
  `$/cancel_request` (A10).
- **honkd shutdown sends nothing upstream.** SIGTERM and SIGKILL must behave the
  same toward goose: no DELETE and no cancel. Turns outlive honkd (A1).
- **SSE read loops never wait on viewers** (A2). `honk-upstream` already reads every
  SSE stream in its own task into an unbounded channel. Viewers get bounded queues,
  and overflow disconnects the viewer. Never use `.send().await` to a viewer from a
  session actor; use `try_send`.
- **Persist before use** (A8, A15). A connection id is written to the state file
  before its first subscribe or request. A pending request is written before it is
  fanned out.
- **Viewer-supplied cwd is never forwarded upstream.** Activation and reconcile
  always pass the stored cwd (from `session/new`, else `session/list`), plus
  `mcpServers: []` (A5, P3b).
- **Public repo:** no secrets, no org names, no `/home/<user>` paths in code,
  fixtures or docs. Use `$HOME` and repo-relative paths. Recordings made with
  `--record` go through `Redactor::from_env()` and are reviewed by eye before any
  commit.
- **Long waits:** the bash tool times out at 120 s. Run live tests with a longer tool
  timeout, or as `systemd-run --user --unit=honk-live-$RANDOM --collect
  --setenv=PATH="$PATH" ...`, and poll the journal.
- **Crate versions:** add dependencies with `cargo add` and don't hand-pin. The code
  below assumes axum 0.8 and tokio-tungstenite ≥ 0.26 (`Message::Text(Utf8Bytes)`).
  Adapt small API differences to whatever `cargo add` resolves, and record any you
  hit in the commit message.
- **Branch:** work on `m1`, branched from `main` after the M0 PR merges, or from
  `m0` if it hasn't. Commit after every task. Don't push the cutover task.
- **Sandbox spend:** live tests use `claude-haiku-4-5@20251001` via
  `session/set_config_option`. Keep prompts short.

## Downstream contract honkd serves (ACP over WS plus `_meta.honk` / `_honk/*`)

| Inbound from viewer | honkd behavior |
|---|---|
| `initialize` | Answered locally, every time (it is pigeon's ping): the cached upstream init result plus `_meta.honk = {protocol:1, version}`. Never forwarded |
| `session/new` | New upstream connection (id persisted first). Forwarded, and the result is returned **verbatim** (pigeon checks `extensionResults`). The WS is auto-attached live |
| `session/load` | Held: replay from the log, then the reply, then `_honk/replay_done`, then re-offer pending requests, then live. `_meta.honk.after` resumes; a foreign epoch → `_honk/reset` + full replay. Not held: cold snapshot from export, no activation. The cwd param is ignored |
| `session/prompt` | `_meta.honk.mode`: absent = `native` (goose semantics: busy error with the run id); `queue`; `steer`. `_meta.honk.client_req_id` is deduped through the ledger. The response goes to the originator at turn end. Auto-attaches |
| `_goose/unstable/session/steer` | Forwarded on the session's connection; consumption is tracked (A12) |
| `session/cancel` (notif) | Upstream cancel + every pending request answered `cancelled` + queue dropped (A9) |
| Response to a forwarded server request | First answer goes upstream; the other viewers get `_honk/request_resolved` |
| `session/close` | Detaches this WS only and replies `{}`. **Never forwarded** |
| `session/list` | Control connection. Each entry gets `_meta.honk = {held, running}` |
| Any other request with `sessionId` | Forwarded on the session's connection (activating if needed); the id is remapped back |
| Any other request without `sessionId` | Forwarded on the control connection |
| `$/cancel_request` | Dropped |
| `_honk/hard_cancel {sessionId}` | DELETE the session connection, then re-activate (A8) |
| `_honk/status {}` | Held sessions, run state, viewers, pending/queue counts |

honkd → viewer notifications: `_honk/reset {sessionId, epoch}`,
`_honk/replay_done {sessionId, epoch, seq}`,
`_honk/request_resolved {sessionId, requestId, reason}`,
`_honk/request_lost {sessionId, toolCallId, suspected:true}`,
`_honk/evicted {sessionId}`. Every logged `session/update` carries
`params._meta.honk = {epoch, seq}`, and in-flight entries carried over by a reconcile
also carry `inflight:true`. Synthesized frames carry `update._meta.honk.synthesized`
or `.source`.

```rust
pub fn guard_url_with(url: &str, allow_production: bool) -> anyhow::Result<Url> {
    let parsed = Url::parse(url).with_context(|| format!("failed to parse URL '{url}'"))?;
    if parsed.port() == Some(PRODUCTION_GOOSE_PORT) && !allow_production {
        anyhow::bail!(
            "refusing to connect to production goose port {PRODUCTION_GOOSE_PORT} \
             (honkd: pass --allow-production-upstream)"
        );
    }
    Ok(parsed)
}

pub fn guard_url(url: &str) -> anyhow::Result<Url> {
    guard_url_with(url, false)
}

/// A non-success HTTP status from goose, kept typed so callers can tell
/// 404 (goose restarted, A13) from 409 (stale subscriber, A2) from the rest.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct HttpStatusError {
    pub op: &'static str,
    pub status: reqwest::StatusCode,
}
impl std::fmt::Display for HttpStatusError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "{} failed with status {}", self.op, self.status)
    }
}
impl std::error::Error for HttpStatusError {}

pub fn status_of(err: &anyhow::Error) -> Option<reqwest::StatusCode> {
    err.chain().find_map(|e| e.downcast_ref::<HttpStatusError>()).map(|e| e.status)
}
pub fn is_gone(err: &anyhow::Error) -> bool {
    status_of(err) == Some(reqwest::StatusCode::NOT_FOUND)
}
```

**Key code** (`transport.rs`). The mailbox lease mirrors goose's slot behavior:

```rust
use std::sync::{Arc, Mutex};
use tokio::sync::mpsc::{UnboundedReceiver, UnboundedSender, unbounded_channel};
use serde_json::Value;

pub type Pred = fn(&Value) -> bool;

pub struct Mailbox {
    pub tx: UnboundedSender<Value>,
    pub slot: Arc<Mutex<Option<UnboundedReceiver<Value>>>>,
    pub lose: Arc<Mutex<Vec<Pred>>>,
}

impl Mailbox {
    pub fn new() -> Self {
        let (tx, rx) = unbounded_channel();
        Self { tx, slot: Arc::new(Mutex::new(Some(rx))), lose: Arc::new(Mutex::new(Vec::new())) }
    }
    /// `None` → caller answers 409 (a subscriber already holds the stream).
    pub fn lease(&self) -> Option<Lease> {
        let rx = self.slot.lock().unwrap().take()?;
        Some(Lease { rx: Some(rx), slot: self.slot.clone(), lose: self.lose.clone() })
    }
}

pub struct Lease {
    rx: Option<UnboundedReceiver<Value>>,
    slot: Arc<Mutex<Option<UnboundedReceiver<Value>>>>,
    lose: Arc<Mutex<Vec<Pred>>>,
}

impl Lease {
    /// Dequeue-then-maybe-drop: at-most-once, like http_server.rs:366-368.
    pub async fn next(&mut self) -> Option<Value> {
        loop {
            let frame = self.rx.as_mut()?.recv().await?;
            let mut lose = self.lose.lock().unwrap();
            if let Some(i) = lose.iter().position(|p| p(&frame)) {
                lose.remove(i);
                continue;
            }
            return Some(frame);
        }
    }
}

impl Drop for Lease {
    fn drop(&mut self) {
        if let Some(rx) = self.rx.take() {
            *self.slot.lock().unwrap() = Some(rx);
        }
    }
}
```

**Run-engine rules (each with its evidence):**

1. `session/prompt` while a run is active → immediate error
   `{"code":-32602,"message":"Invalid params","data":"session already has active run \`<run>\`; use _goose/unstable/session/steer"}`.
   Nothing is persisted. (goose `start_active_run`; pigeon §17 Q2)
2. Otherwise: commit the user message immediately (P5a: the user message persists
   even on cancel), set `run_<uuid>`, and send `session_info_update{activeRunId:run}`.
   Every frame of this run goes to the **prompting connection's** session mailbox
   (A4). The user prompt is not echoed live (A7).
3. A message is committed (it joins `committed`, so load/export see it) when the
   script moves to a step with a different `msg`, or at `End`. The in-flight message
   is never in load or export (A5).
4. `Permission`: send `request_permission` with a uuid id (p4a shape) and wait on a
   oneshot registered **on that connection**. The cancel token is not watched while
   parked (P5c). An answer on another connection gets 202 and is ignored (P4c). On
   `selected` → continue. On `{"outcome":{"outcome":"cancelled"}}` → end the run
   `cancelled`.
5. `session/cancel` (from any connection, A9) is checked between steps: drop the
   uncommitted message (P5a), then send `info_update(null)` and the reply
   `{"stopReason":"cancelled"}`.
6. Steer: `expectedRunId` must equal the active run, else the exact goose errors
   ("no active run to steer" / `{message, expectedRunId, actualRunId}`). On success,
   reply `{messageId:"steer_<uuid>", runId}`. With `Consume`: at the next step
   boundary emit `user_message_chunk{messageId, _meta:{goose:{steer:true}}}` and
   commit it. With `Drop`: discard at run end (`clear_active_run`, A12).
7. DELETE or `restart()` mid-run kills the run with no reply (T5, P5e).
8. `End`: `info_update(null)`, then `usage_update`, then the reply (canonical order).

            Some(method::RESET) => {

                *self = Blocks { resets, ..Default::default() };

                    }
                }
            }
            _ => {}
        }

use std::collections::HashSet;
use honk_wire::{BlockKey, Cursor, block_key, run_state};
use serde_json::{Value, json};

#[derive(Clone, Debug)]
pub struct Entry { pub seq: u64, pub key: Option<BlockKey>, pub frame: Value, pub synthetic: bool, pub inflight: bool }

pub enum Resume<'a> { Delta(&'a [Entry]), Reset(&'a [Entry]) }

pub struct SessionLog { boot: u64, n: u32, epoch: String, next_seq: u64, entries: Vec<Entry> }

const KEPT_STATE: &[&str] = &["session_info_update", "current_mode_update", "config_option_update"];

impl SessionLog {
    pub fn new(boot: u64) -> Self { Self { boot, n: 0, epoch: format!("{boot}.0"), next_seq: 1, entries: Vec::new() } }
    pub fn epoch(&self) -> &str { &self.epoch }
    pub fn entries(&self) -> &[Entry] { &self.entries }
    pub fn head(&self) -> Cursor { Cursor { epoch: self.epoch.clone(), seq: self.next_seq - 1 } }

    pub fn push(&mut self, frame: Value, synthetic: bool) -> &Entry { self.push_inner(frame, synthetic, false) }

    fn push_inner(&mut self, mut frame: Value, synthetic: bool, inflight: bool) -> &Entry {
        let seq = self.next_seq;
        self.next_seq += 1;
        let key = frame.pointer("/params/update").and_then(block_key);
        let mut honk = json!({"epoch": self.epoch, "seq": seq});
        if inflight { honk["inflight"] = json!(true); }
        frame["params"]["_meta"]["honk"] = honk;
        self.entries.push(Entry { seq, key, frame, synthetic, inflight });
        self.entries.last().unwrap()
    }

    pub fn resume(&self, after: Option<&Cursor>) -> Resume<'_> {
        match after {
            Some(c) if c.epoch == self.epoch => {
                let start = self.entries.partition_point(|e| e.seq <= c.seq);
                Resume::Delta(&self.entries[start..])
            }
            _ => Resume::Reset(&self.entries),
        }
    }

    /// A3/A5: rebuild from committed replay + carried in-flight blocks + interleaved live; new epoch.
    pub fn reconcile(&mut self, replay: Vec<Value>, interleaved: Vec<Value>) {
        let key_of = |f: &Value| f.pointer("/params/update").and_then(block_key);
        let committed: HashSet<BlockKey> = replay.iter().filter_map(key_of).collect();
        let replay_kinds: HashSet<String> = replay.iter()
            .filter_map(|f| f.pointer("/params/update/sessionUpdate").and_then(Value::as_str).map(str::to_owned)).collect();
        let old = std::mem::take(&mut self.entries);
        let mut state: Vec<Value> = Vec::new();
        for k in KEPT_STATE {
            if replay_kinds.contains(*k) { continue; }
            let last = old.iter().rev().find(|e| {
                let u = &e.frame["params"]["update"];
                u["sessionUpdate"] == *k && (*k != "session_info_update" || run_state(u).is_some())
            });
            if let Some(e) = last { state.push(e.frame.clone()); }
        }
        let carried: Vec<Value> = old.into_iter()
            .filter(|e| !e.synthetic && e.key.as_ref().is_some_and(|k| !committed.contains(k)))
            .map(|e| e.frame).collect();
        self.n += 1;
        self.epoch = format!("{}.{}", self.boot, self.n);
        self.next_seq = 1;
        for f in replay { self.push_inner(strip_honk(f), false, false); }
        for f in state { self.push_inner(strip_honk(f), false, false); }
        for f in carried { self.push_inner(strip_honk(f), false, true); }
        for f in interleaved {
            if key_of(&f).is_some_and(|k| committed.contains(&k)) { continue; }
            self.push_inner(strip_honk(f), false, false);
        }
    }

    pub fn has_inflight_carry(&self) -> bool { self.entries.iter().any(|e| e.inflight) }
    pub fn clear(&mut self) { self.entries.clear(); }
}

fn strip_honk(mut f: Value) -> Value {
    if let Some(m) = f.pointer_mut("/params/_meta").and_then(Value::as_object_mut) { m.remove("honk"); }
    f
}

impl State {
    pub fn prune_ledger(&mut self, now_unix: u64, max_age_secs: u64, max_done: usize) {
        self.ledger.retain(|_, e| !matches!(e, LedgerEntry::Done { done_unix, .. } if now_unix.saturating_sub(*done_unix) > max_age_secs));
        let mut done: Vec<(String, u64)> = self.ledger.iter()
            .filter_map(|(k, e)| match e { LedgerEntry::Done { done_unix, .. } => Some((k.clone(), *done_unix)), _ => None }).collect();
        if done.len() > max_done {
            done.sort_by_key(|(_, t)| *t);
            for (k, _) in done.iter().take(done.len() - max_done) { self.ledger.remove(k); }
        }
    }

pub fn save_atomic(path: &Path, state: &State) -> anyhow::Result<()> {
    let dir = path.parent().context("state path has no parent")?;
    let tmp = dir.join(format!(".{}.tmp", path.file_name().context("no file name")?.to_string_lossy()));
    {
        let mut f = std::fs::OpenOptions::new().write(true).create(true).truncate(true).mode(0o600).open(&tmp)
            .with_context(|| format!("open {}", tmp.display()))?;
        serde_json::to_writer_pretty(&mut f, state)?;
        f.write_all(b"\n")?;
        f.sync_all()?;
    }
    std::fs::rename(&tmp, path)?;
    std::fs::File::open(dir)?.sync_all()?;
    Ok(())
}

pub struct StateStore { path: PathBuf, state: Mutex<State> }

impl StateStore {
    /// Loads (or creates) `<dir>/state.json`, bumps `boot`, and saves before returning.
    pub fn open(dir: &Path, discard_corrupt: bool) -> anyhow::Result<Self> {
        std::fs::create_dir_all(dir)?;
        let path = dir.join("state.json");
        let mut state = match std::fs::read_to_string(&path) {
            Ok(raw) => match serde_json::from_str::<State>(&raw) {
                Ok(s) => s,
                Err(e) if discard_corrupt => {
                    let ts = std::time::SystemTime::now().duration_since(std::time::UNIX_EPOCH)?.as_secs();
                    std::fs::rename(&path, dir.join(format!("state.json.corrupt-{ts}")))?;
                    tracing::error!(error = %e, "state file corrupt; moved aside, starting empty (connections leak until goose restarts, A15)");
                    State::default()
                }
                Err(e) => anyhow::bail!("state file {} is corrupt ({e}); refusing to start. Re-run with --discard-corrupt-state to move it aside", path.display()),
            },
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => State::default(),
            Err(e) => return Err(e.into()),
        };
        state.version = 1;
        state.boot += 1;
        save_atomic(&path, &state)?;
        Ok(Self { path, state: Mutex::new(state) })
    }
    pub fn boot(&self) -> u64 { self.state.lock().unwrap().boot }
    pub fn snapshot(&self) -> State { self.state.lock().unwrap().clone() }
    /// Apply and persist synchronously. Callers rely on "returned Ok ⇒ on disk" (A8, A15).
    pub fn mutate<R>(&self, f: impl FnOnce(&mut State) -> R) -> anyhow::Result<R> {
        let mut st = self.state.lock().unwrap();
        let r = f(&mut st);
        save_atomic(&self.path, &st)?;
        Ok(r)
    }
}

```rust
use std::collections::VecDeque;
use honk_wire::PromptMode;
use serde_json::{Value, json};
use crate::rpc;

pub type ViewerId = u64;

#[derive(Clone, Debug, PartialEq)]
pub struct OwnerRef { pub viewer: Option<ViewerId>, pub downstream_id: Value, pub client_req_id: Option<String> }

#[derive(Clone, Debug, PartialEq)]
pub struct Queued { pub owners: Vec<OwnerRef>, pub params: Value, pub mode: PromptMode }

#[derive(Clone, Debug, PartialEq)]
pub struct Inflight { pub upstream_id: String, pub owners: Vec<OwnerRef>, pub params: Value, pub mode: PromptMode, pub announced: bool, pub run_ended: bool }

#[derive(Clone, Debug, PartialEq)]
pub struct PendingSteer { pub upstream_id: String, pub owner: OwnerRef, pub params: Value }

#[derive(Clone, Debug, PartialEq)]
pub struct Steer { pub message_id: String, pub run_id: String, pub owner: OwnerRef, pub params: Value, pub confirmed: bool }

#[derive(Clone, Debug, PartialEq)]
pub enum Reply { Result(Value), Error(Value) }

#[derive(Debug, PartialEq)]
pub enum Action {
    SendPrompt { upstream_id: String, params: Value },
    SendSteer { upstream_id: String, params: Value },
    SynthUser { params: Value, owner: OwnerRef },
    Reply { owners: Vec<OwnerRef>, body: Reply },
    CheckSteersInExport { steers: Vec<Steer> },
}

pub struct IdGen { boot: u64, n: u64 }
impl IdGen {
    pub fn new(boot: u64) -> Self { Self { boot, n: 0 } }
    /// Unique across honkd restarts: a late reply to a pre-restart id can never match a new request.
    pub fn next(&mut self) -> String { self.n += 1; format!("hk{}-{}", self.boot, self.n) }
}

fn synth_end() -> Reply { Reply::Result(json!({"stopReason":"end_turn","_meta":{"honk":{"synthesized":true}}})) }

#[derive(Default, Debug)]
pub struct TurnCore {
    pub run: Option<String>,
    pub inflight: Option<Inflight>,
    pub queue: VecDeque<Queued>,
    pub pending_steers: Vec<PendingSteer>,
    pub steers: Vec<Steer>,
}

impl TurnCore {
    pub fn busy(&self) -> bool { self.run.is_some() || self.inflight.is_some() }

    pub fn on_prompt(&mut self, owner: OwnerRef, params: Value, mode: PromptMode, ids: &mut IdGen) -> Vec<Action> {
        match mode {
            PromptMode::Native => match (&self.run, &self.inflight) {
                (Some(run), _) => vec![Action::Reply { owners: vec![owner], body: Reply::Error(rpc::busy_error(run)) }],
                (None, Some(_)) => { self.queue.push_front(Queued { owners: vec![owner], params, mode }); vec![] } // answered when the run id is announced
                (None, None) => self.dispatch(vec![owner], params, mode, ids),
            },
            PromptMode::Queue => {
                if self.busy() || !self.queue.is_empty() { self.queue.push_back(Queued { owners: vec![owner], params, mode }); vec![] }
                else { self.dispatch(vec![owner], params, mode, ids) }
            }
            PromptMode::Steer => match (self.run.clone(), self.inflight.is_some()) {
                (Some(run), _) => self.send_steer(owner, params, &run, ids),
                (None, true) => { self.queue.push_front(Queued { owners: vec![owner], params, mode }); vec![] }
                (None, false) => self.dispatch(vec![owner], params, mode, ids),
            },
        }
    }

    fn send_steer(&mut self, owner: OwnerRef, params: Value, run: &str, ids: &mut IdGen) -> Vec<Action> {
        let upstream_id = ids.next();
        let mut sp = params.clone();
        sp["expectedRunId"] = json!(run);
        self.pending_steers.push(PendingSteer { upstream_id: upstream_id.clone(), owner, params });
        vec![Action::SendSteer { upstream_id, params: sp }]
    }

    fn dispatch(&mut self, owners: Vec<OwnerRef>, params: Value, mode: PromptMode, ids: &mut IdGen) -> Vec<Action> {
        let upstream_id = ids.next();
        self.inflight = Some(Inflight { upstream_id: upstream_id.clone(), owners, params: params.clone(), mode, announced: false, run_ended: false });
        vec![Action::SendPrompt { upstream_id, params }]
    }

    fn dispatch_next(&mut self, ids: &mut IdGen) -> Vec<Action> {
        match self.queue.pop_front() {
            Some(q) if !self.busy() => self.dispatch(q.owners, q.params, q.mode, ids),
            Some(q) => { self.queue.push_front(q); vec![] }
            None => vec![],
        }
    }

    pub fn on_run_state(&mut self, run: Option<String>, ids: &mut IdGen) -> Vec<Action> {
        let mut out = vec![];
        match run {
            Some(r) => {
                self.run = Some(r.clone());
                if let Some(inf) = self.inflight.as_mut() && !inf.announced {
                    inf.announced = true;
                    out.push(Action::SynthUser { params: inf.params.clone(), owner: inf.owners[0].clone() });
                }
                while let Some(q) = self.queue.front() {
                    match q.mode {
                        PromptMode::Native => { let q = self.queue.pop_front().unwrap(); out.push(Action::Reply { owners: q.owners, body: Reply::Error(rpc::busy_error(&r)) }); }
                        PromptMode::Steer => { let q = self.queue.pop_front().unwrap(); let o = q.owners[0].clone(); out.extend(self.send_steer(o, q.params, &r, ids)); }
                        PromptMode::Queue => break,
                    }
                }
            }
            None => {
                self.run = None;
                if let Some(inf) = self.inflight.as_mut() { inf.run_ended = true; }
                let (confirmed, unconfirmed): (Vec<Steer>, Vec<Steer>) = self.steers.drain(..).partition(|s| s.confirmed);
                if !confirmed.is_empty() { out.push(Action::Reply { owners: confirmed.into_iter().map(|s| s.owner).collect(), body: synth_end() }); }
                if !unconfirmed.is_empty() { out.push(Action::CheckSteersInExport { steers: unconfirmed }); }
                if self.inflight.is_none() { out.extend(self.dispatch_next(ids)); }
            }
        }
        out
    }

    pub fn on_prompt_reply(&mut self, upstream_id: &str, frame: &Value, ids: &mut IdGen) -> Vec<Action> {
        let Some(inf) = self.inflight.take_if(|i| i.upstream_id == upstream_id) else { return vec![] };
        if let Some(run) = rpc::busy_run_id(frame) {
            // A run honkd did not start (goose CLI, scheduler: design §6). Never resend blindly.
            self.run = Some(run);
            return match inf.mode {
                PromptMode::Native => vec![Action::Reply { owners: inf.owners, body: Reply::Error(frame["error"].clone()) }],
                PromptMode::Queue => { self.queue.push_front(Queued { owners: inf.owners, params: inf.params, mode: PromptMode::Queue }); vec![] }
                PromptMode::Steer => { let o = inf.owners[0].clone(); self.on_prompt(o, inf.params, PromptMode::Steer, ids) }
            };
        }
        let body = match frame.get("error") {
            Some(e) => Reply::Error(e.clone()),
            None => Reply::Result(frame.get("result").cloned().unwrap_or(json!({}))),
        };
        let mut out = vec![Action::Reply { owners: inf.owners, body }];
        if inf.run_ended || !inf.announced { self.run = None; }
        if self.run.is_none() { out.extend(self.dispatch_next(ids)); }
        out
    }

    /// Run ended (activeRunId null) but the reply never came (A3). Called by the actor after a grace.
    pub fn finalize_without_reply(&mut self, ids: &mut IdGen) -> Vec<Action> {
        let Some(inf) = self.inflight.take_if(|i| i.run_ended) else { return vec![] };
        let mut out = vec![Action::Reply { owners: inf.owners, body: synth_end() }];
        out.extend(self.dispatch_next(ids));
        out
    }

    pub fn on_steer_reply(&mut self, upstream_id: &str, frame: &Value, ids: &mut IdGen) -> Vec<Action> {
        let Some(pos) = self.pending_steers.iter().position(|s| s.upstream_id == upstream_id) else { return vec![] };
        let ps = self.pending_steers.remove(pos);
        if let Some(r) = frame.get("result") {
            self.steers.push(Steer {
                message_id: r["messageId"].as_str().unwrap_or_default().into(),
                run_id: r["runId"].as_str().unwrap_or_default().into(),
                owner: ps.owner, params: ps.params, confirmed: false,
            });
            return vec![];
        }
        if rpc::is_no_active_run(frame) { return self.on_prompt(ps.owner, ps.params, PromptMode::Queue, ids); }
        if let Some(actual) = rpc::mismatch_actual_run(frame) { self.run = Some(actual.clone()); return self.send_steer(ps.owner, ps.params, &actual, ids); }
        vec![Action::Reply { owners: vec![ps.owner], body: Reply::Error(frame["error"].clone()) }]
    }

    /// A12 confirmation: the steer's messageId appeared as a live user_message_chunk.
    pub fn on_user_message(&mut self, message_id: &str) {
        if let Some(pos) = self.steers.iter().position(|s| s.message_id == message_id) {
            let s = self.steers.remove(pos);
            match self.inflight.as_mut() {
                Some(inf) => inf.owners.push(s.owner),
                None => self.steers.push(Steer { confirmed: true, ..s }),
            }
        }
    }

    /// After the actor checked export for unconfirmed steers.
    pub fn steers_checked(&mut self, found: Vec<Steer>, missing: Vec<Steer>, ids: &mut IdGen) -> Vec<Action> {
        let mut out = vec![];
        if !found.is_empty() { out.push(Action::Reply { owners: found.into_iter().map(|s| s.owner).collect(), body: synth_end() }); }
        for s in missing.into_iter().rev() { self.queue.push_front(Queued { owners: vec![s.owner], params: s.params, mode: PromptMode::Queue }); }
        if !self.busy() { out.extend(self.dispatch_next(ids)); }
        out
    }

    /// A9: queued prompts are dropped; the inflight owner gets goose's own `cancelled` reply.
    pub fn on_cancel(&mut self) -> Vec<Action> {
        let mut out = vec![];
        let dropped: Vec<OwnerRef> = self.queue.drain(..).flat_map(|q| q.owners).collect();
        if !dropped.is_empty() {
            out.push(Action::Reply { owners: dropped, body: Reply::Result(json!({"stopReason":"cancelled","_meta":{"honk":{"reason":"dropped_on_cancel"}}})) });
        }
        let steer_owners: Vec<OwnerRef> = self.steers.drain(..).map(|s| s.owner).chain(self.pending_steers.drain(..).map(|s| s.owner)).collect();
        if !steer_owners.is_empty() { out.push(Action::Reply { owners: steer_owners, body: Reply::Result(json!({"stopReason":"cancelled"})) }); }
        out
    }

    /// A13 goose restart / hard cancel: the run is gone; never auto-resend the prompt.
    pub fn interrupt(&mut self, reason: &str) -> Vec<Action> {
        let mut owners: Vec<OwnerRef> = self.inflight.take().map(|i| i.owners).unwrap_or_default();
        owners.extend(self.steers.drain(..).map(|s| s.owner));
        owners.extend(self.pending_steers.drain(..).map(|s| s.owner));
        self.run = None;
        if owners.is_empty() { return vec![]; }
        vec![Action::Reply { owners, body: Reply::Result(json!({"stopReason":"cancelled","_meta":{"honk":{"reason":reason}}})) }]
    }

    pub fn attach_waiter(&mut self, client_req_id: &str, owner: OwnerRef) -> bool {
        let has = |os: &Vec<OwnerRef>| os.iter().any(|o| o.client_req_id.as_deref() == Some(client_req_id));
        if let Some(inf) = self.inflight.as_mut() && has(&inf.owners) { inf.owners.push(owner); return true; }
        if let Some(q) = self.queue.iter_mut().find(|q| has(&q.owners)) { q.owners.push(owner); return true; }
        false
    }
}

            Err(mpsc::error::TrySendError::Closed(_)) => false,

use axum::{Router, extract::{Query, State, ws::{WebSocketUpgrade, rejection::WebSocketUpgradeRejection}}, http::{HeaderMap, StatusCode}, response::{IntoResponse, Response}, routing::get};

pub fn router(hub: Arc<crate::hub::Hub>) -> Router {
    Router::new().route("/acp", get(acp_get)).with_state(hub)
}

fn ct_eq(a: &str, b: &str) -> bool {
    a.len() == b.len() && a.bytes().zip(b.bytes()).fold(0u8, |acc, (x, y)| acc | (x ^ y)) == 0
}

/// Auth: X-Secret-Key header OR ?token= (pigeon's WebSocket can only do the latter).
/// Plain GET without upgrade → 406, matching goose, which pigeon's preflight reads as "reachable".
async fn acp_get(
    State(hub): State<Arc<crate::hub::Hub>>,
    headers: HeaderMap,
    Query(q): Query<HashMap<String, String>>,
    ws: Result<WebSocketUpgrade, WebSocketUpgradeRejection>,
) -> Response {
    let presented = headers.get("x-secret-key").and_then(|v| v.to_str().ok()).map(str::to_owned).or_else(|| q.get("token").cloned());
    if !presented.is_some_and(|p| ct_eq(p.trim(), &hub.cfg.secret)) {
        return StatusCode::UNAUTHORIZED.into_response();
    }
    match ws {
        Ok(ws) => ws.on_upgrade(move |sock| crate::hub::viewer_loop(hub, sock)),
        Err(_) => StatusCode::NOT_ACCEPTABLE.into_response(),
    }
}
```

`viewer_loop` splits the socket. A writer task drains the `ViewerTx` receiver, and
when `kill` fires it sends close code `4001 "slow consumer"` and exits. The reader
parses each text message and dispatches on `rpc::kind`. In the skeleton:
`initialize` → local reply; `session/new` → `hub.create_session`; `session/prompt` /
steer / other session methods → that session's handle (auto-attaching this viewer
live-only first). On socket end it sends `Detach` to every session it attached.

`hub.create_session(cwd, params)`:
1. `Upstream::initialize_with(...)` with `client_capabilities: {"fs":{"readTextFile":false,"writeTextFile":false},"terminal":false}`
   (no elicitation in M1; see Deviations).
2. `state.mutate(|s| s.orphan_conns.push(conn_id))` **before** the first subscribe
   (A15).
3. Subscribe to the conn stream, then `call("session/new", params with _meta.honk stripped)`.
4. Subscribe to the session stream, then
   `state.mutate(|s| { remove the orphan; s.sessions.insert(sid, HeldSession{conn_id, cwd, ..}) })`.
5. Spawn the actor and return the **verbatim** result.

`serve(cfg, listener: std::net::TcpListener, ready: Option<oneshot::Sender<()>>)`:
open the `StateStore`, build the hub, wrap the listener with
`tokio::net::TcpListener::from_std`, run `axum::serve`, and fire `ready` once
accepting.

pub struct Viewer { ws: WebSocketStream<MaybeTlsStream<tokio::net::TcpStream>>, next: u64, inbox: VecDeque<Value>, pub blocks: Blocks, pub closed: Option<u16> }

impl Viewer {
    async fn open(req: impl IntoClientRequest + Unpin) -> Self {
        let (ws, _) = tokio_tungstenite::connect_async(req).await.unwrap();
        Viewer { ws, next: 0, inbox: VecDeque::new(), blocks: Blocks::default(), closed: None }
    }
    /// honk-style: header auth.
    pub async fn connect(h: &Harness) -> Self {
        let mut req = h.ws_url().into_client_request().unwrap();
        req.headers_mut().insert("x-secret-key", h.secret.parse().unwrap());
        let mut v = Self::open(req).await;
        v.call("initialize", json!({"protocolVersion":1,"clientCapabilities":{}})).await;
        v
    }
    /// pigeon-style: ?token= auth and pigeon's exact initialize.
    pub async fn connect_pigeon(h: &Harness) -> Self {
        let mut v = Self::open(format!("{}?token={}", h.ws_url(), h.secret)).await;
        v.call("initialize", json!({"protocolVersion":1,"clientCapabilities":{"fs":{"readTextFile":false,"writeTextFile":false}}})).await;
        v
    }
    pub async fn send(&mut self, v: Value) { self.ws.send(Message::Text(v.to_string().into())).await.unwrap(); }
    pub async fn request(&mut self, method: &str, params: Value) -> Value {
        self.next += 1;
        let id = json!(self.next.to_string());
        self.send(json!({"jsonrpc":"2.0","id":id,"method":method,"params":params})).await;
        id
    }
    pub async fn call(&mut self, method: &str, params: Value) -> Value {
        let id = self.request(method, params).await;
        self.response(&id, SECS).await
    }
    async fn read(&mut self, t: Duration) -> Option<Value> {
        loop {
            match tokio::time::timeout(t, self.ws.next()).await {
                Ok(Some(Ok(Message::Text(s)))) => { let v: Value = serde_json::from_str(&s).unwrap(); self.blocks.apply(&v); return Some(v); }
                Ok(Some(Ok(Message::Close(c)))) => { self.closed = c.map(|c| u16::from(c.code)); return None; }
                Ok(Some(Ok(_))) => continue,
                _ => return None,
            }
        }
    }
    pub async fn recv(&mut self, t: Duration) -> Option<Value> {
        if let Some(v) = self.inbox.pop_front() { return Some(v); }
        self.read(t).await
    }
    pub async fn response(&mut self, id: &Value, t: Duration) -> Value {
        self.wait_for(t, |f| f.get("id") == Some(id) && f.get("method").is_none()).await
    }
    /// Consumes frames up to and including the first match (all frames are applied to `blocks` on read).
    pub async fn wait_for(&mut self, t: Duration, pred: impl Fn(&Value) -> bool) -> Value {
        let deadline = tokio::time::Instant::now() + t;
        let mut skipped = VecDeque::new();
        while let Some(f) = self.inbox.pop_front() { if pred(&f) { self.inbox = skipped; return f; } skipped.push_back(f); }
        loop {
            let left = deadline.saturating_duration_since(tokio::time::Instant::now());
            let f = self.read(left).await.unwrap_or_else(|| panic!("timeout/close waiting; saw {skipped:?}"));
            if pred(&f) { self.inbox = skipped; return f; }
            skipped.push_back(f);
        }
    }
}

pub fn prompt_params(sid: &str, text: &str, client_req_id: Option<&str>, mode: Option<&str>) -> Value {
    let mut p = json!({"sessionId": sid, "prompt": [{"type":"text","text":text}]});
    let mut honk = serde_json::Map::new();
    if let Some(c) = client_req_id { honk.insert("client_req_id".into(), json!(c)); }
    if let Some(m) = mode { honk.insert("mode".into(), json!(m)); }
    if !honk.is_empty() { p["_meta"] = json!({"honk": honk}); }
    p
}

}

### Task 11: Reattach and reconcile inside a running honkd

**Risk (A2/A3/A5):** this is the subtle core. The rules below are exhaustive;
don't improvise.

**Files:**
- Modify: `crates/honkd/src/session.rs`
- Test: `crates/honkd/tests/reconcile.rs`

**Rules:**
1. `StreamEnded` on the session or conn stream → `reattach()`: `subscribe` both
   streams with `set_subscribe_deadline(Duration::MAX)` and backoff from 100 ms up
   to 5 s. On 409, log a warning every 30 s while waiting. **Never DELETE** (A2). On
   `is_gone` → the goose-restart path (Task 17).
2. After resubscribing, **always reconcile** (A3): send
   `session/load {sessionId, cwd: stored, mcpServers: []}` on the same connection
   (A4, A5). Collect `session/update`s until the load reply. Frames whose key is
   committed (it shows up in replay) count as replay. Before the load reply, any
   frame whose key is not yet seen in replay is buffered as "interleaved". The
   buffer is classified once the reply arrives, since the full replay set is only
   known then (P3a interleaving).
3. Call `log.reconcile(replay, interleaved)`, then broadcast `_honk/reset`, the
   full log, and `_honk/replay_done` to every viewer (the reset frames go through
   `offer`; if a viewer overflows, it is evicted and reattaches).
4. **Run-state probe** after the load reply (Wire facts): idle + an inflight
   prompt with no reply → `TurnCore::on_run_state(None)` and then, after
   `turn_end_grace`, `finalize_without_reply` (A3). Push a synthesized
   `session_info_update {activeRunId:null, _meta.honk.synthesized:true}` into the
   log so that viewers see the turn end. Active + no known run → `on_run_state(Some(actual))`.
5. **dirty flag.** Set it when a reconcile carried in-flight entries
   (`log.has_inflight_carry()`). While dirty: (a) at the first live frame whose
   message id differs from every carried in-flight message id (a message boundary,
   so the carried message is now committed), reconcile again *before* fanning out
   that frame; (b) at turn end, reconcile again. Clear dirty when a reconcile
   carries nothing. This guarantees that viewers get the committed version of a
   gapped message before any later message. `honk tail`'s no-duplication guarantee
   (Task 21) depends on it.
6. Turn end = prompt reply OR `activeRunId:null` OR probe idle (A3). Never the
   reply alone.

### Task 16: Lost-request detection and `_honk/hard_cancel` (A8)

**Files:**
- Modify: `crates/honkd/src/session.rs`
- Test: `crates/honkd/tests/lost_request.rs`

**Detection rule** (it is advisory, because long silent tools look the same):
1. A reattach happened during the current run, and
2. the session mode (tracked from `current_mode_update` / forwarded `set_mode`) is
   `approve` or `smart_approve` (in `auto` goose never asks), and
3. some `Tool(id)` in the log has a `tool_call` but no `tool_call_update` and no
   pending request for that `toolCallId`, and
4. no upstream frame arrived for `lost_request_after` (default 20 s; tests use
   500 ms) after the reconcile, and the probe says the run is still active.

Then broadcast `_honk/request_lost {sessionId, toolCallId, suspected:true}` once per
`toolCallId`.

**Hard cancel** (`_honk/hard_cancel {sessionId}` request): this is the only
viewer-triggered DELETE.
1. `state.mutate` moves `conn_id` to `orphan_conns`.
2. `up.delete()` (cancels even a parked run: P2d, P4c), then remove the id from
   orphans.
3. Make pending requests stale (Task 13 rule 5) and call `turn.interrupt("hard_cancel")`.
4. Re-activate: new connection (persisted first), subscribe, `session/load` with the
   stored cwd, reconcile, reset viewers.
5. Reply `{}` to the requester.

### Task 17: goose restart (A13)

**Files:**
- Modify: `crates/honkd/src/{session.rs,hub.rs}`
- Test: `crates/honkd/tests/goose_restart.rs`

**Behavior:**
1. Any `is_gone` (404) on POST, GET or reattach → the session is `Gone`. The
   control connection also re-initializes on 404 (backoff 200 ms → 5 s;
   `initialize` works after ~200 ms, P5e).

   `stopReason:cancelled, _meta.honk.reason:"upstream_restart"`). Pending entries

   non-empty queue re-activate in order, 500 ms apart. Others re-activate on first

   and is dropped without DELETE, since it is already 404) + `session/load` with the
   stored cwd + reconcile + `_honk/reset`.
4. Then the kept queue dispatches.

**TailRenderer rules.** The "no duplicated text" guarantee: printed text per
block is always a prefix of the truth, because honkd reconciles at message
boundaries and turn end (Task 11 rule 5).
1. Normal mode. A text chunk for key K: if K differs from the last printed block,
   print a header (`\n` for agent text; `\n> ` for user; `\n[thinking] ` for thought,
   and only with `--thoughts`). Then print the chunk and append it to `printed[K]`.
   `tool_call` → `\n▸ {title}` once per id. A `tool_call_update` with
   `completed`/`failed` → ` ✓`/` ✗` once per id.
2. `_honk/reset` → replay mode. Accumulate `shadow[K]` and note whether each K's
   replay entries are `inflight` (carried, `params._meta.honk.inflight`).
3. `_honk/replay_done`, for each K in replay order:
   - not printed before and not inflight → print it all;
   - printed, non-inflight, and `shadow[K].starts_with(printed[K])` → print only the
     suffix;
   - printed and diverged (not a prefix) → print
     `\n[honk: {K} changed on reconcile]\n` plus the full text. This should be
     unreachable, and a test asserts it doesn't happen in the gap scenario;
   - printed but absent from replay, or present only as inflight → **quarantine** K.
     Later live chunks for K are buffered, not printed, until a reset in which K
     appears non-inflight; then apply the suffix rule.
4. `text_only` mode (for tests): prints only agent text, with no headers or tool
   lines.

## Deviations from the brief (with reasons)

1. **Absent `_meta.honk.mode` means `native`, not `steer`.** When a run is active,
   honkd answers with goose's exact busy error (with the run id), and pigeon then
   steers on its own (`session-runner.ts:363-407`). Unmodified pigeon keeps working,
   and its error-string parsing stays valid. `mode: "steer"` is fully implemented
   (Tasks 8, 15) for clients that ask for it, and raw pigeon steers still get A12
   consumption confirmation and re-queue.
2. **Downstream auth accepts `?token=` as well as `X-Secret-Key`.** Pigeon's Node
   WebSocket cannot send headers (`ws-transport.ts:18-36`). A plain GET returns
   406 and a bad token 401, because pigeon's preflight classifies reachability
   that way.
3. **No elicitation capability upstream in M1** (design §4 says "elicitation yes").
   There is no form-capable viewer until M3. Advertising it would park turns for up
   to 300 s instead of goose auto-cancelling as it does today. Turn it on with the M3
   form UI.
4. **The pigeon change is `client_req_id` plus a one-time resend after a disconnect
   when talking to honkd**, not adopting `mode: steer`. Without it, `kill -9 honkd`
   costs pigeon the receipt (`DisconnectedDuringTurn`) even though the turn
   completes.
5. **The cutover must repoint pigeon's stored per-session endpoints.** Pigeon
   prefers `session.backend_endpoint` over `PIGEON_GOOSE_ACP_URL`, so changing the
   env alone leaves existing sessions on :4080.
6. **Pigeon auto-answers permissions (`options[0]` = allow_always) and races
   humans.** Pending requests go to every attached viewer, including pigeon WSs
   (auto-attached to sessions they prompt). That matches today's behavior; a
   per-viewer opt-out is deferred to M3.
7. **Two extra small crates.** `honk-wire` holds shared raw-Value helpers
   (`BlockKey`, `Cursor`, `HonkMeta`, the `Blocks` reducer), so `honk` doesn't depend
   on `honkd`; it holds no ACP types. `honk-fake-goose` is a dev-only crate shared by
   the honkd and honk tests. `honk` also gets a lib target for testability.
8. **Run-state probe:** a steer with a bogus `expectedRunId`. honkd needs "is the
   run still active?" after a reattach where the reply and run-end were lost (P2d),
   and export has no run state. goose's `require_active_run` rejects before
   queueing anything, so the probe has no side effects. That is source-verified
   only; Task 22 test 5 verifies it live.
9. **Reconcile triggers go beyond the brief.** As well as after every reattach and
   at turn end, honkd re-reconciles at the first message boundary while "dirty", and
   tags carried entries `inflight`. Without this, `honk tail` would reprint or
   misorder a message that had a gap at the reattach, and the "no duplicated text"
   exit criterion could fail.
10. **Full replay (no `replayTail`) for reconcile in M1.** It is simpler and correct.
    Turn-end reconciles happen only on dirty turns, so the full replay isn't paid on
    every turn.
11. **If the prompt reply is lost, honkd synthesizes `end_turn`** with
    `_meta.honk.synthesized: true`. goose persists no stopReason, so the real one is
    unknowable.
12. **Lost-request detection is gated on `approve`/`smart_approve` mode and a
    reattach, and is surfaced as `suspected`.** A long silent tool in `auto` mode
    looks identical, and false alarms would push users toward DELETE.
13. **Small `honk-upstream` API additions** (Task 1): production opt-in, client
    capabilities, `request_with_id`, `recv`, `unsubscribe`, typed HTTP status. honkd
    needs restart-unique request ids (`hk<boot>-<n>`) and 404/409 discrimination.
14. **`session/close` from a viewer means detach, and is never forwarded**, since it
    cancels any connection's run (§3).
15. **Corrupt state file:** honkd refuses to start unless
    `--discard-corrupt-state` is passed. Silently starting empty would leak every
    held connection (A15).
